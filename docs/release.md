# 发布规范

先读 `AGENTS.md`。本文件仅适用于发布工作。

版本号采用 `vYYYY.M.S` 格式。

| 字段 | 含义 | 规则 |
|:---|:---|:---|
| `YYYY` | 发布年份 | 项目确认基准日期对应的 4 位公历年份 |
| `M` | 发布月份 | `1`–`12`，不补前导零 |
| `S` | 月度发布序号 | 每月从 `1` 开始，跨月重置，不补前导零 |

## 基准日期

年份取自项目元数据、`RELEASE_DATE` 或用户显式确认。不得自行推断；缺失时询问用户。

## 核心约束

- 版本号全局唯一；任何字段不得有前导零。错误示例：`v2026.03.1`、`v2026.11.01`。
- 仅正式 Release/Tag 递增 `S`；普通 commit 不计入。
- 未经用户显式授权，不触发发布、不创建 tag、不 push 到远程。
- Release 构建成功且 PR 合并后，删除本地临时分支。删除远程分支需要用户显式授权。
- Release notes 按模块或类别摘要（`Features`、`Bug Fixes`、`Performance`、`Documentation`）；不要堆砌 commit 日志。

## 版本演进

- 同月：`v2026.10.1` → `v2026.10.2` → `v2026.10.3`
- 跨月重置：`v2026.10.3` → `v2026.11.1`
- 跨年重置：`v2026.12.2` → `v2027.1.1`
